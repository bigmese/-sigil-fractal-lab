# Sigil Atlas Lab v3

This package contains a three-engine procedural geometry prototype:

- Seal engine
- Cosmological map engine
- Symbolic device engine

## Upload structure

Place these directly in the GitHub repository root:

```text
index.html
styles.css
app.js
README.md
core/
engines/
```

The `core` folder must contain:

```text
dna.js
random.js
renderer.js
state.js
```

The `engines` folder must contain:

```text
seal.js
cosmology.js
device.js
```

For GitHub Pages, publish from:

- Branch: main
- Folder: / (root)
