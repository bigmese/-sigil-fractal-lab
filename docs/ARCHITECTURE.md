# SymbolDNA G0.3.0 Architecture

```text
Identity + Intent
        ↓
Deterministic Seed
        ↓
Append-only Symbol Atlas
        ↓
Structural Blueprint
        ↓
Hidden Construction Geometry
        ↓
Curves / Glyph Compression / Terminals
        ↓
SVG Renderer + Export
```

## Rendering layers

1. Construction circles
2. Radial axes and guide lines
3. Anchor points
4. Visible curves and boundaries
5. Identity glyph path
6. Terminals and final color

Construction geometry is hidden after synthesis unless the user enables **Show construction**.

## Evidence handling

- Historical and corpus-derived records keep their original status.
- Rejected universal claims remain visible in the Atlas.
- Experimental hypotheses are not promoted to historical fact.
- Intention profiles are a clearly labeled experimental interface layer.
