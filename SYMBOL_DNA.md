# Symbol DNA

## Core Symbol identity

A Core Symbol ID is derived from:

- the deterministic identity fingerprint
- the selected intention IDs
- the cousin index

The Core Symbol ID is designed to remain stable when the same symbolic identity is evolved against a later Atlas snapshot.

## Full Symbol Code

The checksummed `SD2...` code additionally pins:

- Atlas version
- generator version
- identity fingerprint
- intention selection
- cousin index

Raw birth details are not stored in the code.

## Structural DNA

The current eight values configure the existing generator armature:

- Boundary: closure and outer enclosure
- Centrality: center prominence
- Radiality: sectors, spokes, and perimeter positions
- Connectivity: linked-node and path density
- Nesting: structural layers and bands
- Angularity: polygonal versus curved construction
- Flow: sequential, curved, or directed movement
- Repetition: repeated terminals, motifs, and positions

The values remain experimental until a broader corpus supports promotion.
